OFFLINE LUDO 4 - Android Studio project

What is included
- Offline, four-player pass-and-play Ludo.
- Two dice are rolled together, then used separately in order.
- After the first die, tap a token; then tap a token for the second die.
- Four tokens per player, 6 to leave the yard, captures, safe squares, and a home finish.
- Runs locally in an Android WebView; no internet permission is requested.

Build an APK
1. Install Android Studio (current stable) on a computer.
2. Extract this ZIP.
3. In Android Studio choose Open, then select the OfflineLudo4_Android folder.
4. Allow Gradle sync and install the Android SDK Platform 35 if prompted.
5. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).
6. The APK is normally at app/build/outputs/apk/debug/app-debug.apk.
7. Copy that APK to your Android phone and install it. You may need to allow installation from that file manager.

Important
This package is the complete Android Studio source project, not a precompiled APK. This workspace does not have the Android SDK/Gradle build environment needed to compile and verify an APK here. The game is a basic playable implementation; house rules and board artwork can be refined after testing.
